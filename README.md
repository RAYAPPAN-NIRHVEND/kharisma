# Kharisma Birthday Project 🌹
## Cara Upload ke GitHub

### Struktur Folder:
```
/
├── kharisma-birthday.html    (229KB) ← Main website
├── our-playlist.html         (13KB)  ← Music player  
├── our-story-book.html       (3.6MB) ← Photo book
├── 22-reasons-kharisma.html  (19KB)  ← 22 Reasons cards
└── assets/
    ├── images/               ← 24 foto (total ~8MB)
    ├── audio/                ← 11 lagu (total ~38MB)
    └── video/                ← 3 video (total ~9MB)
```

### Cara Upload:
1. Buat repo baru di GitHub (private!)
2. Upload SEMUA file & folder assets sekaligus
3. Enable GitHub Pages di Settings → Pages
4. Website live di: https://username.github.io/repo-name

### Catatan:
- Pastikan folder `assets/` ikut diupload
- Jika tidak ada assets folder, foto/lagu tidak akan muncul
